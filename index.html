Grace RE-Envisioned

What's our goal?

Ever since Roblox Grace was discontinued, I had the feeling I could remake it in Godot — an open-source game engine. Some Grace players quit along the way, and some were waiting for a real alternative.

Grace hit its lowest player count of 700 just a week before September 2026. That kept me motivated to continue development, even after setting aside my other game, "Inferno."

Things have been going well so far, and I'm happy I started this project.

On which devices will the game be released?

We are focusing on itch.io, Flatpak, and GitHub Releases.

Android users can use GitHub Releases or F-Droid (still working on that). For Windows, it's all handled by the launcher below.

Launcher for Windows?

Installing software on Windows is more tedious than on Linux (Flatpak) or Android, so we're making a launcher that downloads the binaries from GitHub Releases.

Releases are tagged with the sequence 0.Xv, where X is the version number, and the launcher checks for new releases via web fetch.

The launcher isn't made with C++ — it's built entirely in Godot, which has good support for system calls.
